# YUZUちゃんが歌う 日南ゆずピール

日南ゆずピールの販売サイトのデモ版です。静的HTML/CSS/JavaScriptで構成し、ビルドや依存パッケージのインストールは不要です。

## プレビュー

```bash
cd /workspace/yuzu-peel-website
python3 -m http.server 8000 --bind 0.0.0.0
```

同じマシンのブラウザから `http://localhost:8000` を開きます。クラウド環境でポート転送機能がある場合は、8000番ポートをブラウザで開いてください。ホームページの外部公開は行っていません。

ダウンロードしたファイルをPCで確認する場合は、フォルダー構成を保って `index.html` をブラウザで直接開くこともできます。

## 画像・動画・リンクの差し替え

`site-config.js` の次の値を編集してください。

- `heroImage`: 商品写真のパス。画像を `assets/` に置いて指定します。
- `heroImageAlt`: 写真の説明。
- `isDemoImage`: 正式な商品写真に変更したら `false` にします。
- `youtubeVideoId`: 公開済みYouTube動画の11文字のID。空欄なら「準備中」を表示します。
- `aiCityNichinanUrl`: 確認済みの「愛シティ日南」公式HTTPS URL。指定URL `https://evasive-nichinan-future-port.base44.app/` を設定済みです。新しいタブで開きます。

商品説明・仮価格は `index.html` で編集できます。パッケージはCSSで描いた仮デザインです。実際の写真にする場合は `.package-stage` 内の仮パッケージを画像に置き換えてください。

トップ画像はAI生成のデモイメージで、実際の商品写真ではありません。楽しみ方の挿絵は絵文字で、端末によって見え方が変わります。

## 販売について

通常袋300円・箱入り1,000円は仮価格です。購入ボタンは準備中ダイアログを表示し、注文・決済処理やデータ送信は行いません。架空のお客様の声や実績は掲載していません。

公開前に公式リンク、実際の商品写真、内容量、原材料、アレルギー情報、税込価格、送料、販売者情報・特定商取引法に基づく表記、購入方法を確認・追加してください。
